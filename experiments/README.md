# Experiments

One folder per experiment, each with its own `README.md` covering:

- **Question** — what was being tried or measured.
- **Setup** — how to reproduce it (scripts involved, place settings, player count).
- **Result** — what actually happened, including numbers for anything performance-related.
- **Next** — what to change if it gets picked back up.

Scripts that only belong to one experiment can live in its folder. Once
something proves reusable, promote it into `src/shared`.
